## 一、先说结论：上架前必须确认类目

| 事项 | 现状 | 影响 |
|---|---|---|
| 电子资源类目范围 | 一级类目「电子资源」**只有三个二级类目**：PPT/简历/其他模版、课件/教案/手抄报、头像壁纸 | **题库/资料不在其中** |
| 考试真题 | 《电子资源类商品管理规范》3.2 明确把**考试真题（如考研、公务员考试真题）**列为禁售的「敏感类商品」 | 商品内不得含真题，宣传中也不能提 |
| 走「书籍」类目 | 需《出版物经营许可证》（营业执照经营范围含「出版物零售/批发」）+ 图书 ISBN / 报刊 CN | 资质门槛更高 |
| 教辅宣传 | 《出版物行业管理规范》9.4 禁止宣称「包过」「保分」「XX题必考」 | 宣传文案要清 |

**上架前第一步：定类目**。类目定不下来，后面所有信息填写都是空谈。

## 二、母规则：《小红书商家商品发布规范》（2025-01-15 生效）

### 2.1 基本要求（第四条）

- **完整、一致、真实**：商品主要信息要完整明示；标题、主图、属性、详情各版块要素一致；不得夸大、过度、虚假承诺效果。
- **禁止发布的信息**，包括但不限于：
  - 使用代表党和国家形象的元素，或利用国家重大活动、重大纪念日、国家机关及其工作人员名义宣传；
  - 表示商品功效的断言或保证；非保健食品宣传保健功能；
  - 与药品相混淆的用语，暗示疾病预防、治疗；
  - 与其他商品对比、贬低其他商品；
  - 「无效退款」「XX保险公司保险」；
  - **「100%有效」「零风险」「安全」「无毒副作用」「无依赖」等承诺性表述**；
  - 有效率、治愈率；
  - 利用国家机关/事业单位/医疗机构/学术机构/行业组织名义形象，或专家、医务人员、消费者名义为功效作证明；
  - **「最高技术」「最科学」「最先进」「最佳」「国家级商品」「填补国内空白」等绝对化或排他性用语**；
  - 无法证实的「科学或研究发现」「实验或数据证明」。
- **不得推送第三方信息**（第四条五）：社交 / 导购 / 团购 / 促销 / 购物平台等第三方网站或客户端的**名称、LOGO、二维码、超链接、联系方式、银行账号**。
- **不得重复铺货**（第四条六）：店铺中同时出售**同款或极其近似商品两件以上**。

### 2.2 字段要求

| 字段 | 要求 |
|---|---|
| 类目（第五条） | 逐级选择正确类目，不得把商品发布在与实际品类不一致的类目下 |
| 类目准入（第六条） | 有资质要求的类目须符合《小红书经营类目资质要求》 |
| 商品标题（第八条） | 可含品牌、品名、基本属性（材质/功能/特征）、规格参数（型号/颜色/尺寸/规格/用途/货号）；**不应包含无关品牌及无关信息** |
| 商品图片（第九条，实物商品） | 主图 3–9 张；首图必须为商品正面实物图；**不许图片拼接、水印**；不得含促销、夸大描述文字（促销只能用官方商品戳）；主图中须有清晰可放大的商品标签图 |
| 商品类型（第十条） | 如实描述全新/二手、预售/现货/拍卖/一口价 |
| SKU（第十一条） | 不得在属性里标注与属性无关的信息；**不得利用 SKU 价格引流**，不得以非常规数量单位发布商品 |
| 价格（第十二条） | 遵守《小红书商品价格管理规范》 |
| 七天无理由（第十四条） | 按规范选择并履行 |

## 三、电子资源类商品（**2026-02-10 生效**）— 与商品包最直接相关

### 3.1 允许出售需同时满足（3.1）

1. 符合法律法规及平台规则，不侵犯他人知识产权、著作权、肖像权；无色情、暴力、违法内容；
2. **权益边界清晰**：可明确界定交付内容（如「含 15 套 PPT 模板，格式 pptx」）、使用期限（如「1 年有效期」）、使用范围（如「仅限个人非商用」）；
3. **支持数字化交付且交付流程可追溯**：需通过平台消息、短信、邮箱等**可留存记录**的方式发送，**不得仅通过「私信联系」等无追溯渠道交付**；
4. 内容完整可使用，符合商品描述中的质量标准。

### 3.2 禁止出售（3.2）

| 类别 | 内容 |
|---|---|
| 侵权类 | 盗版电子书、未授权影视剪辑素材、盗用他人设计的模板、非官方授权软件安装包（如破解版 PS） |
| **敏感类** | **考试真题（如考研、公务员考试真题）**、学校内部教案、涉密资料、涉及个人隐私的数据信息 |
| 功能异常类 | 无法打开的模板文件、有病毒风险的软件/插件、失效的 AI 工具、分辨率低于 72dpi 的模糊壁纸 |
| 易纠纷类 | **「效果不可量化」的资源（如「保证提升成绩的课件」）**、内容重复的拼凑型模板、无明确使用权限的模糊软件插件 |
| 其他 | 依法禁止或平台认为不适宜出售的 |

### 3.3 商品信息要求（第四条）

**标题**：不得带有任何与商品真实信息无关的文字或符号，且需如实描述。参考格式：
- PPT/简历/其他模版：`模版类型 + 适用场景 + 数量 + 适用系统 + 是否有水印 + 使用期限`
- 课件/教案/手抄报：`资源类型 + 适用学段/学科 + 核心内容 + 使用期限`
- 头像壁纸：`资源类型 + 风格 + 数量 + 分辨率 + 使用期限`

**主图**：
- 格式：JPG / JPEG / PNG
- 比例：**1:1 或 3:4**
- 像素：**≥800×800，或 ≥750×1000px**
- 大小：**≤3M**
- 不得侵犯第三方合法权益或有其他违法情况

**详情必须告知（模板类 12 项，逐项写全）**：
1. 模版类型（不得只写「通用模板」）
2. 资源数量（含子文件要同步说明）
3. 设计风格（不得用「百搭风格」等模糊表述）
4. 适用系统
5. **有效期**（不得写「终身免费更新」等模糊承诺）
6. **是否有水印**（明确「是」或「否」）
7. 兼容性（软件及版本，不兼容部分要特别说明）
8. 页数范围
9. 可修改范围
10. **使用权限**（商用 / 非商用）
11. 配套服务
12. **发货方式：统一标注「自动发货」**

### 3.4 内容宣传规范（第五条）

1. 视频/直播中介绍的信息（资源类型、数量、权益、有效期、兼容性）必须与详情页、实际交付**完全一致**，不得「宣传与实物不符」；
2. 演示内容与实际功能一致，不得通过剪辑、特效**伪造功能效果**；
3. **禁止「终身」「永久」等不可兑现承诺**；不得宣传「永久会员」「终身更新」「长期免费使用」；期限要精确（如「购买后 2 年内可下载，下载后可永久使用」），不得用「长期有效」等模糊表述；
4. 不得价格虚假宣传，不得虚假宣称「底价」「最低价」，有优惠价必须**清晰且明显提醒**；
5. **不得诱导第三方**：明确引导消费者私下交易、发布联系方式及平台未接入的第三方平台信息、通过非官方渠道交易、私信使用不规范行为。

### 3.5 发货与售后

- 发货模式**固定为「自动发货」**（第六条）。
- 七天无理由退货（第七条）。
- **售后服务申请时限：订单确认收货后 15 天内**（因虚拟商品特殊性，比一般商品短）。

## 四、出版物行业（**2026-07-29 生效**）— 若走「书籍/杂志/报纸」类目

**资质**：营业执照经营范围须含「出版物零售」或「出版物批发」；须取得**《出版物经营许可证》**；经营 K12 教材需额外提供教材经营资质或新华书店授权；图书须有国家新闻出版署核发的 **ISBN**，报刊须有 **CN**。

**禁止出售**：危害国家安全、破坏民族团结、宣扬邪教迷信、淫秽色情低俗、暴力恐怖、非法出版物（无 ISBN/CN/ISRC）、侵权盗版、走私出版物等。

**宣传红线（第九条）**：
- 不得以「绝版」「孤本」「市面唯一」等做无依据的稀缺性宣传；
- 不得虚构「诺贝尔推荐」「教育部指定」「XX 名人亲笔签名」等权威背书；
- **不得使用最佳、第一、顶级、国家级等广告禁用极限词**；
- 不得虚构出版社定价、原版售价、海外售价，不得用「进货价」「成本价」「亏本甩卖」误导，不得宣称「全网最低价」「底价包邮」「一元一本」「书店倒闭」；
- 不得断章取义或误导性摘引；不得以「内附独家资料」「附赠答案手册」宣传实际不含的内容；
- **教辅类商品不得宣称「包过」「保分」「XX题必考」等无法兑现的效果承诺**；
- 不得发布诱导私下交易的内容（含在商品详情、直播间话术、笔记评论中留存站外联系方式或第三方平台信息）。

## 五、滥发信息与质量管理（2026 年现行）

### 5.1 《【商品滥发信息】违规管理细则》（2026-04-30 生效）

| 违规场景 | 说明 |
|---|---|
| 必要信息缺失 | 受国家特殊管控商品未在显著位置标明必须说明的事项（字体过小、图片模糊、对比度低都算「未显著标明」） |
| 售卖商品主体不明确 | 标题/主图/详情/规格信息混乱、矛盾或过于泛化；以「福袋」「盲盒」售卖但未公示内部具体品类或范围 |
| 专拍链接 | 把「补差价」「补运费」「邮费专拍」类非实物链接挂在实物类目下 |
| 过期/临期 | 售卖已过期商品；商详未以清晰有效形式呈现时间信息 |
| 不规范宣传 | 使用误导性、夸大性或被明令禁止的宣传用语及素材 |

**处理阶梯**：情节轻微（首次）下架商品 → 情节一般 冻结商品并禁止重新上架 → 情节严重 限制店铺流量与新商品上架 → 情节特别严重 冻结店铺。

### 5.2 《小红书商品描述及质量管理总则》（2026-01-03 生效）

描述不符或抽检不合格分 A/B/C/D 四类，按店铺近 60 天累计次数递进：

| 次数 | A 类 | B 类 | C 类 | D 类 |
|---|---|---|---|---|
| 首次 | 商品冻结 + 同类商品下架 3 天 + 违约金 2000 元 + 资金冻结 60 天 | 商品下架 + 违约金 1000 元 | 商品限流/下架 + 违约金 200 元 | 限时整改 / 降权 |
| 二次 | 商品冻结 + 违约金 4000 元 + 全量商品下架 3 天 | 商品冻结 + 违约金 2000 元 + 资金冻结 30 天 | 降权/下架 + 违约金 500 元 | 降权/下架 + 违约金 200 元 |
| 三次及以上 | **店铺清退** + 违约金 5000 元 + 资金冻结 90 天 | **店铺清退** + 违约金 4000 元 + 资金冻结 90 天 | 下架 + 永久冻结 + 违约金 1000 元 | 下架 + 违约金 500 元 |

## 六、商品标题与文案的极限词（与笔记侧同一份词表）

《「虚假宣传：广告禁用词」实施细则》**2026-03-20 生效**，**裸「最」也在列**。商品标题、主图文字、详情页、直播间话术、评论都要避开。完整清单见
`xhs-question-bank-pipeline/references/platform-rules.md` 第三节，本 skill 的 `scripts/platform_rule_scan.py` 已内置。

另《「虚假宣传：承诺保证」实施细则》**2026-03-24 生效**直接点名「**包过（考证/考试）**」，并禁「零基础速成」「轻松掌握」「一次通过」「保过」「无效退款」等。

## 七、上架自检清单（每次打包后过一遍）

- [ ] **类目已确认**（题库/资料能否归入现行类目；若不能，先决定走哪条路）
- [ ] **商品内不含考试真题**、不含学校内部教案、不含涉密资料、不含他人隐私数据
- [ ] 标题只写真实信息，不含无关品牌与无关信息，格式按三·3.3
- [ ] 主图 JPG/PNG、1:1 或 3:4、≥800×800、≤3M、无拼接无水印无促销文字
- [ ] 详情写全 12 项必告信息，**发货方式标注「自动发货」**
- [ ] 无「终身」「永久」「长期有效」类不可兑现承诺，期限写具体
- [ ] 无「底价」「最低价」「全网最低价」「亏本甩卖」等价格虚假宣传
- [ ] 无联系方式、二维码、第三方平台名称/LOGO/链接（含「下单后联系客服」这类指向站外沟通的表述）
- [ ] 不重复铺货：同款或极其近似商品不超过 1 件
- [ ] SKU 属性里没有与属性无关的信息，没有用 SKU 价格引流
- [ ] 商品标题/主图/详情/直播间话术四处信息一致，不「宣传与实物不符」
- [ ] 跑一遍 `python scripts/platform_rule_scan.py <商品文案文件>`，命中为 0
