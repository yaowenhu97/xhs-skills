# 一键小红书商品包（关键词 → 完整商品包 ZIP）

用户**只发送关键词**，本 skill 自动完成**抓目录 → 主图 → 详情图 → 规格图 → 打包**，输出完整商品包到桌面。

## 调用

```powershell
# —— 单关键词（兼容旧版）——
$env:KW = "黑龙江定向选调生"
python ...\xhs-auto-package\scripts\make_package.py

# —— 批量（推荐：多个关键词整合为一个数据包）——
$env:KWFILE = "C:\Users\root\Desktop\关键词.txt"    # 每行一个关键词
$env:GROUP_NAME = "第1组"                            # 可选，默认：单关键词用关键词名/多个用"批量"
python ...\xhs-auto-package\scripts\make_package.py
# 或用 $env:KW = "关键词1,关键词2" 逗号分隔多个
```

## ✅ 千帆商品发布合规（Step 1.6，上架前必做）

**完整规则**见 [references/qianfan-product-rules.md](references/qianfan-product-rules.md)（2026-09-12 抓自官方正文，逐条标生效时间）。

**上架前必须先定类目**（这是最容易被忽略、后果最重的一条）：
- 一级类目「电子资源」**只有三个二级类目** —— PPT/简历/其他模版、课件/教案/手抄报、头像壁纸，**题库/资料不在其中**；
- 该规范 3.2 明确把**考试真题（如考研、公务员考试真题）**列为禁售的「敏感类商品」，商品内不得含真题，宣传中也不能提；
- 改走「书籍」类目则需《出版物经营许可证》+ 图书 ISBN，且《出版物行业管理规范》（2026-07-29 生效）禁止教辅宣称「包过」「保分」「XX题必考」。

**关键字段要求**（电子资源类，2026-02-10 生效）：

| 项 | 要求 |
|---|---|
| 主图 | JPG/JPEG/PNG；**1:1 或 3:4**；**≥800×800 或 ≥750×1000px**；**≤3M**；无拼接、无水印、无促销文字 |
| 标题 | 不得带与真实信息无关的文字或符号；格式＝类型＋适用场景＋数量＋适用系统＋是否有水印＋使用期限 |
| 详情 | 写全 12 项必告信息（类型/数量/风格/适用系统/有效期/是否有水印/兼容性/页数范围/可修改范围/使用权限/配套服务/**发货方式＝自动发货**） |
| 交付 | 权益边界清晰、数字化交付**可追溯**，**不得仅通过「私信联系」等无追溯渠道交付** |
| 售后 | 因虚拟商品特殊性，**售后申请时限为确认收货后 15 天内** |

**宣传红线**：禁「终身」「永久」「长期有效」等不可兑现承诺（期限要写具体）；禁「底价」「最低价」等价格虚假宣传；**禁诱导第三方**（引导私下交易、发布联系方式或平台未接入的第三方信息）；禁「宣传与实物不符」。

**投放前跑扫描**（词表含官方广告禁用词、承诺保证词、商品侧红线，裸「最」也在列）：

```bash
python scripts/platform_rule_scan.py "<商品标题与文案文件>"
```

命中必须为 **0**。脚本同时覆盖《小红书商家商品发布规范》的绝对化用语（最高技术/最科学/最先进/最佳/国家级商品/填补国内空白）与「100%有效/零风险/安全/无毒副作用/无依赖」等承诺性表述。

**上架自检清单**（逐项打勾，详见参考文档第七节）：类目已确认 / 不含考试真题 / 标题只写真实信息 / 主图规格达标 / 详情 12 项写全且标「自动发货」 / 无终身永久类承诺 / 无价格虚假宣传 / 无联系方式与第三方信息 / 不重复铺货 / SKU 属性无无关信息 / 四处信息一致 / 扫描命中为 0。

> ⚠️ **待确认项**：当前商品包的 SKU 目录名含「（下单后联系客服）」字样（如 `笔试+面试（下单后联系客服）/`）。《电子资源类商品管理规范》3.1(3) 要求交付走可留存记录的追溯渠道、第五条(5) 禁「引导消费者私下交易」，这类命名有擦边风险。**是否改名需你确认后再动 make_package.py**，本次未改。


## 5 步流水线（make_package.py）

| 步骤 | 脚本 | 说明 |
|------|------|------|
| ① 抓目录 | `xinshe-directory-render\scripts\fetch_directory.py` | Chrome 9222 接管，Ctrl+K 搜索，抓章节分类/资料包/历年真题（可选，无 Chrome 自动跳过） |
| ② 主图 | `scripts\render_main.py` | 关键词红字黑体居中叠加笔试题库底图，字号自适应 |
| ③ 详情图 | `xinshe-directory-render\scripts\render_directory.py` | 目录数据渲染多张 3:4 竖版 JPG（上下居中/靠左/字号层序化） |
| ④ 规格图 | 复制 `assets\sku_*.jpg` | 4 张 SKU 规格图 |
| ⑤ 打包 | 内置 zipfile | `{KW}_商品包.zip` → 桌面 |

## 资产（assets\）

- `sku_bishi.jpg` / `sku_mianshi.jpg` / `sku_bishi_mianshi.jpg` / `sku_60min.jpg`（已改为时政包规格图，文件名保留历史命名）：4 张规格图

## 关键参数
- 主图：CENTER_X=720, CENTER_Y=1055, MAX_W=1120, 红字(230,51,18)+深红描边, 字号按字数自适应(4字320/6字280/8字240/10字200/12字170)
- 详情图：字号 小节32/子分类28/小字26, 行距34, 上下居中+靠左（详见 xinshe-directory-render SKILL）

## 坑点
- 抓取需 Chrome 启动 `--remote-debugging-port=9222 --user-data-dir=非默认` 并已登录；否则自动跳过①，用已有 `{KW}_最终目录.md`
- PowerShell 传中文用 `$env:KW`（ProcessStartInfo.Arguments 会破坏中文）
- 详情图渲染要排除「面试资料」被误判为笔试资料（否则资料包重复+面试丢失）
