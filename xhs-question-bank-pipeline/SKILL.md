# 小红书笔记全流程（题库抓取 → 图片+文案+审查）

把"心社助手平台的笔试题库"做成可发布的小红书笔记。覆盖完整流水线：**题库抓取 → 核心信息提取 → HTML 生成 → PNG 截图 → 100 字文案 → 合规审查**。

## 输入

- **心社助手关键词**（如 "2026年XX公司笔试题库"）+ 用户登录了心社助手平台（http://124.221.67.217）
- **或** 已有的题库素材 `.md` 文件（直接跳过 Step 1，从 Step 2 开始）

## 输出（每条流水线产生）

| 产物 | 保存位置 |
|------|----------|
| 题库目录 Markdown | `C:\Users\root\Desktop\笔记\素材\{题库名}.md` |
| 小红书笔记 HTML | `C:\Users\root\Desktop\笔记\素材\小红书笔记\{考试名}·小红书笔记.html` |
| 5 张 PNG（封面+4 内容页） | `C:\Users\root\Desktop\笔记\素材\小红书笔记\PNG\{考试名}_p1.._p5.png` |
| 100 字小红书文案 | 对话中输出 |
| 合规审查报告 | 对话中输出 |

## 标准流程（6 步）

### Step 1 — 抓取题库（可选：已有素材可跳过）

详见 [reference.md](reference.md) Part 2 "心社助手抓取规则"。

**关键规则**：
- 只使用用户提供的完整关键词，不缩写、不拆词、不去后缀
- 禁止降级搜索：完整关键词无结果立即停下汇报
- Ctrl+K → Ctrl+V 粘贴完整关键词 → 暂停 2s → 按 Enter
- **仅抓"刷题"和"资料"两个 Tab 的目录信息**，不下载任何 PDF/PPTX/题目内容
- **不点击**"查看全部/预览/开始做题/下载"
- 按 [reference.md](reference.md) Part 2 "Markdown 输出格式"模板填字段
- 保存到 `C:\Users\root\Desktop\笔记\素材\{题库名}.md`

> 用户已提供 .md 素材时，**直接跳过 Step 1**，从 Step 2 开始。

### Step 2 — 提取核心信息

从素材提取以下字段用于封面与文案：
```
报名人数 / 岗位数 / 报名起止时间 / 笔试日期 / 笔试科目
面试形式 / 报考条件（学历/年龄/政治面貌/资历截止）
开考比例 / 合格线 / 单位性质
```

### Step 3 — 生成 HTML

按 [reference.md](reference.md) Part 1 "HTML 模板" 生成 5 页 1080×1440 小红书笔记：

| 页 | 内容 |
|----|------|
| 1 | 封面：标签 + 大标题 + 副标题 + 4 个 KPI + 报名时间段 + 备注 |
| 2 | 报名与条件：时间线表 + 报考条件清单 |
| 3 | 笔试：科目 pill + 题型清单 + 合格线 |
| 4 | 资料目录：按素材的资料模块分组 |
| 5 | 面试 + 建议：面试形式 + 题型清单 + 备考建议 |

**关键 CSS（已验证）**：
- `.page { width:1080px; height:1440px; display:flex; flex-direction:column; }`
- 封面 `.cover { height:1376px; display:flex; column; justify-content:center; align-items:center; }`
- 内容页 `.page:not(.page-cover) { padding:36px 40px; }`、`.card { flex:1 0 auto; }`
- 字号：h1 70px、kpi-num 56px、reg-time-value 32px、table 18px、group-list 19px、card-h2 32px
- **截图 helper（必须保留在 `</body>` 前）**：
  ```html
  <script>(function(){var m=location.search.match(/[?&]p=(\d+)/);if(!m)return;var n=parseInt(m[1])-1;var ps=document.querySelectorAll('.page');ps.forEach(function(el,i){if(i!==n)el.style.setProperty('display','none','important');});})();</script>
  ```

**主题色**：按考试选一套 accent（蓝/青绿/红/绿等），全身统一。变量速查见 [reference.md](reference.md)。

### Step 4 — Chrome headless 截图

用 [scripts/render_png.ps1](scripts/render_png.ps1) 一键批量：

```powershell
powershell -File scripts/render_png.ps1 -HtmlDir "C:\path\to\html" -OutDir "C:\path\PNG"
```

- 截图前 HTML 复制到纯 ASCII 临时路径（避免 file:// 中文解析失败）
- 按 `?p=1..5` 各截一张 → 每份素材 5 张 PNG
- 输出到 `C:\Users\root\Desktop\笔记\素材\小红书笔记\PNG\`

### Step 5 — 生成 100 字文案

- 标题 ≤20 字（突出"单位 + 年份 + 关键数字"）
- 正文 ≤1000 字（通常 100–150 字），核心信息为主
- 小红书风格，emoji 克制
- **先做 Step 6 改写**，再用改写版写正文

### Step 6 — 合规审查（必做，以官方平台规则为准）

**规则依据**：
- `references/platform-rules.md`（社区规范 + 官方广告禁用词 + 承诺保证 + 交易笔记细则 + 千帆商品规则摘要）
- `references/shutiao-and-ad-rules.md`（薯条协议与取数边界 + 聚光《禁止推广目录》+ 聚光《教育行业规则》——备考类业务最对口的一份）
- 两份均为 2026-09-12 抓取自官方域名，逐条标生效时间。

**先跑扫描脚本**（词表已按官方最新版落地，含裸「最」）：

```bash
python scripts/platform_rule_scan.py "C:\path\to\笔记目录"
```

命中必须为 **0** 才算通过。脚本覆盖：官方广告禁用词（2026-03-20 生效）、承诺保证词（2026-03-24 生效）、标题党句式、导流（电话/邮箱/微信/裸网址/门牌地址）、商品侧红线。

**高频必改**（官方词表命中后的改写方向）：

| 命中 | 替换为 |
|------|------|
| 裸「最」：最后 / 最低 / 最终 / 最新 / 最常见 / 最容易 | 临近截止 / 合格线 / 总成绩 / 当年 / 常见 / 容易 |
| 绝对（含「绝对化表述」这类答题术语） | 表述过满 / 说法过满 / 过满措辞 / 实际名额 |
| 领先 / 引领 | 高出 / 占优；引导 |
| 首个 / 首次 / 首选 | 头一个 / 头一次 / 优先位置 |
| 独家 / 唯一 / 一流 / 国家级 / 世界级 | 单列 / 仅有 / 覆盖面宽 / 全国性 / 全球范围 |
| 包过 / 保过 / 稳过 / 一次通过 / 100% | 提高效率 / 系统复习 / 稳妥通过 |
| 微信号 / 私信 / 扫码 / 二维码 / 链接 / 电话 / 邮箱 / 门牌地址 | 删除，指路写「以官方公告载明的渠道为准」 |
| 机构名（中公/华图/粉笔）/ 备考群 / 公众号 / 咨询电话 | 删除 |
| 招聘 / 招录人 | 报名 / 报名人数 |
| 上岸 / 上岸率 | 通过 / 录用 / 顺利入选 |
| 公务员 / 考公 / 考编 / 编制 / 入编 | 机关行政岗位 / 机关单位工作人员 / 非编岗位 / 劳动合同制聘用 |
| 选调生 / 国考 / 省考 | 定向招录 / 中央招录 / 省级招录 |
| 辅警 | 警务辅助岗位 |
| 理财 / 股票 / 基金 / 证券（金融类素材常见） | 财富管理 / 股权 / 在上海主板挂牌上市 |
| 国旗国歌国徽（宪法常识） | 国家标志 |
| 研判类：押题 / 密卷 / 内部资料 / 保过班 | 删除或改「系统复习资料」 |

**禁发商品及信息**见 [reference.md](reference.md) Part 4（21 大类）。典型高风险：医美/诊疗/整形/减肥增高/偏方；铁路/航空器整机配件；枪支弹药/毒品/危险化学品/烟草；仿小红书账号/店铺/logo；代考/代办发票/指标/代抢车票；私彩/赌博/外挂/私服。

**⚠️ 同一素材多版（V1–V6）的发布风险**：官方《违规蹭流量》细则将「一段时间内多次重复发布相同或相似笔记内容（含素材、标题、封面、情节）」列为违规，《治理公告》直接治理「只改标题几个字」的近似笔记。查重达标只说明文本差异够大，**同一素材的多版务必错开发布间隔、分散到不同素材之间**，不要在同一账号短时间连发。

**图片合规**：无水印/二维码/链接/联系方式/小红书 logo/录屏；AI 生成图建议标注「AI 配图」。

**⚠️ 高敏题材**：
- 医疗健康（卫健委/医院）→ 禁投行业，仅保留报名事实、删疗效承诺
- 公考/选调生 → 监管重点，彻底合规改写（「上岸」→「通过」、「选调生」→「定向招录」）
- **21 大禁发品类**（ID 1349）→ 笔记若涉及医美、诊疗、铁路/航空设备、仿小红书、赌博、外挂、代考代办、毒品、枪支、烟草、动植物保护等关键词，立即删除或重写

**公考 13 高危场景**逐一 ✅/❌。
