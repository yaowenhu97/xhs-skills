## 一、图片规格（生成的图直接受约束）

### 1.1 信息类商品（走 B 路径 / 电子资源类，**2026-02-10 生效**）

| 项 | 要求 | 对生成图的约束 |
|---|---|---|
| 格式 | JPG / JPEG / PNG | 输出的 PNG 可直接用；JPG 也可 |
| 比例 | **1:1 或 3:4** | 本 skill 的 3:4 竖版符合要求，不要出 4:5、9:16 |
| 像素 | **≥800×800，或 ≥750×1000px** | 1080×1440 达标 |
| 大小 | **≤3M** | ⚠️ 比「平台通用 ≤5MB」更严，导出时按 3M 压 |
| 内容 | 不得侵犯第三方合法权益或其他违法情况 | 不用他人原图/素材 |

**主图不得**：图片拼接、水印、促销或夸大描述文字（促销只能用官方商品戳）。

### 1.2 实物商品（走 A 路径，**2025-01-15 生效**）

- 主图 **3–9 张**；**首图必须为商品正面实物图**，能清晰看到商标及商品名称等信息；
- **不许图片拼接、水印**，不得包含促销、夸大描述等文字说明；
- 主图中须有清晰平整可放大的**商品标签图**（产品名称、编号、主要原料、营养成分表、执行标准、生产日期保质期等；食品类尤其严格）；
- 图片应突出商品主体，清晰美观，不失真。

> ⚠️ 本 skill 的「促销主图」模板（带 promotional badge / sale atmosphere）与 A 路径主图规范冲突——**促销元素不要放在主图**，可放到种草图或详情图；确需促销信息只能用平台官方商品戳。

## 二、标题规则

| 来源 | 要求 |
|---|---|
| 商品发布规范 第八条 | 可含品牌、品名、基本属性（材质/功能/特征）、规格参数（型号/颜色/尺寸/规格/用途/货号）；**不应包含无关品牌及无关信息** |
| 电子资源类 4.1 | 不得带任何与商品真实信息无关的文字或符号；格式＝类型＋适用场景＋数量＋适用系统＋是否有水印＋使用期限 |
| 电子资源类 4.3 | 不得用「通用模板」「百搭风格」「长期有效」等模糊表述 |

> ⚠️ 本 skill 的爆款标题公式里有「反差/对比」型（如「79元拿下大牌同款」）与「情绪型」（如「软糯到哭」）。**对比型要避免贬低其他商品**（商品发布规范第四条三：不得与其他商品对比、贬低其它商品）；同时**不得虚构价格对比**（电子资源类第五条(4)：不得虚假宣传价格福利、不得虚假宣称「底价」「最低价」）。

## 三、商品详情必告信息（信息类 / 模板类 12 项，逐项写全）

1. 模版类型（不得只写「通用模板」）
2. 资源数量（含子文件要同步说明）
3. 设计风格（不得用「百搭风格」等模糊表述）
4. 适用系统
5. **有效期**（不得写「终身免费更新」等模糊承诺）
6. **是否有水印**（明确「是」或「否」）
7. 兼容性（软件及版本，不兼容部分要特别说明）
8. 页数范围
9. 可修改范围
10. **使用权限**（商用 / 非商用）
11. 配套服务
12. **发货方式：统一标注「自动发货」**

## 四、宣传红线（文案与图片文字都要过）

### 4.1 广告禁用词（《「虚假宣传：广告禁用词」实施细则》**2026-03-20 生效**）

**裸「最」也在列。** 完整词表见扫描脚本，重点：

| 类别 | 代表词 |
|---|---|
| 最族 | 最、最佳、最优、最好、最大、最高、最低、最低价、最新、最先、最先进 |
| 一族 | 第一、全国第一、全网第一、销量第一、排名第一、NO.1、TOP.1、仅此一次、唯一、独一无二、一流 |
| 级/极族 | 国家级、世界级、极品、极佳、绝佳、绝对、极致、顶级、顶尖、尖端、终极 |
| 首族 | 首个、首选、首款、首家、首席、首次、首屈一指、首创 |
| 绝对化表述 | 世界领先、遥遥领先、领导者、领军者、领先、引领、王者、之王、王牌、冠军、销量冠军、率先、开创、史无前例、无与伦比、无可替代、不二之选 |
| 风险回报 | 100.00%、100%有效、百分之百、0成本、绝对、绝佳、空前、无双、万能、永久、全能 |
| 品质类 | 金牌、老字号、祖传、纯天然、无添加、无敌、免检 |
| 方法唯一类 | 唯一、特批、独创、独家配方、独家 |
| 虚假承诺 | 包过、一本书学会、一套题学会、一次通过、一次通关、保过、不用学直接选、看到直接选 |
| 财富增值 | 保值、升值、升值回报、投资价值、投资回报 |

### 4.2 承诺保证（《「虚假宣传：承诺保证」实施细则》**2026-03-24 生效**）

**直接点名「包过（考证/考试）」**。另禁：

- 效果类：100%有效、奇效、神效、必定有效、根治、永不复发、彻底解决、无效退款
- 安全类：零风险、绝对安全、无毒副作用、无依赖、无刺激、无添加、纯天然、无害、无副作用
- 时限剂量式：如「每天 2 粒，7 天腰围缩小 5cm」「敷 15 分钟色斑减淡 50%」
- 结果诱导：包涨粉、包火、包获客、包盈利、包学会、包分配工作、保证提高升学率、零基础速成、轻松掌握、躺着赚钱
- **展示学员成功案例（收益/粉丝/获奖/录取）并暗示购买后能达到同样效果**

### 4.3 价格与其他

- **不得价格虚假宣传**：不得虚假宣称「底价」「最低价」「全网最低价」，不得用「进货价」「成本价」「亏本甩卖」误导；有优惠价必须**清晰且明显提醒**；
- **禁「终身」「永久」「长期有效」等不可兑现承诺**，期限写具体（如「购买后 2 年内可下载，下载后可永久使用」）；
- **禁诱导第三方**：引导私下交易、发布联系方式、发布平台未接入的第三方平台信息、非官方渠道交易；
- **禁推送第三方信息**：社交/导购/团购/促销/购物平台的名称、LOGO、二维码、超链接、联系方式、银行账号；
- **禁「宣传与实物不符」**：图里宣称的数量/权益/有效期/兼容性必须与实际交付一致，演示不得用剪辑特效伪造效果；
- **不得重复铺货**：店铺中同款或极其近似商品不超过 1 件（多 SKU 商品尤其注意规格不能「极其近似」）。

## 五、商品笔记的内容红线（笔记形态同样适用）

| 规则 | 禁止内容 |
|---|---|
| 标题党（内容质量差细则） | 两性内涵；明显超出常理、过于夸张不实；与内容完全不符；「千万不要买…」「没想到…」「XXX真的没有骗我」「不xx不是中国人」句式 |
| 不当营销 | 绝对性功效/效果承诺；伪装消费者视角推荐自家产品；**借用社会专业身份（医生/教师/律师/国家公职人员/金融从业者）打造人设营销**；生硬插入与正文不相关的广告；大字报式低价噱头 |
| 违规蹭流量 | 蹭热度、不相关/弱相关、虚报价格、**重复发布**（一段时间内多次重复发布相同或相似内容，含素材、标题、封面、情节） |
| 无资质科普 | 具体法律案例分析、医疗建议、**投资理财与股票涨跌趋势**需相应资质 |
| 利益诱导 / 恶意骗赞 | 点赞自取、四连拿图、虚假噱头诱导双击 |

> ⚠️ 本 skill 的文案模板含「姐妹们冲就完了」「回购 3 次」「被闺蜜问爆」这类表达——属于小红书常见口吻，但注意：**「回购 N 次」「被闺蜜问爆」若并非真实经历，属于「伪装真实消费者体验」**（不当营销细则）。自用分享要真的自用，代运营/商家自己发时不要伪装成消费者视角。

## 六、上架自检清单

- [ ] **类目已确认**（信息类商品：电子资源一级类目下只有 PPT/简历模版、课件/教案/手抄报、头像壁纸三个二级类目，题库不在其中；且禁售**考试真题**）
- [ ] 图片：比例 1:1 或 3:4、≥800×800、**≤3M**、无拼接无水印无促销文字
- [ ] 实物商品首图为商品正面实物图，主图 3–9 张，含可放大的商品标签图
- [ ] 标题只写真实信息，不含无关品牌与模糊表述，无「底价/最低价」
- [ ] 详情写全 12 项必告信息，**发货方式标「自动发货」**
- [ ] 无「终身」「永久」「长期有效」类承诺，期限写具体
- [ ] 无联系方式、二维码、第三方平台名称/LOGO/链接
- [ ] 不重复铺货（同款或极其近似商品不超过 1 件）
- [ ] 标题/主图/详情/文案四处信息一致，不「宣传与实物不符」
- [ ] 文案无标题党句式、无伪装消费者视角、无利益诱导
- [ ] 跑 `python scripts/platform_rule_scan.py <标题与文案文件>`，命中为 **0**
